# FastMultiTools (Vite MPA)

A high-performance, static, multi-page tools website built with Vite and Vanilla JS.

## Commands
- `npm install`
- `npm run dev`
- `npm run build`
- `npm run preview`

## Highlights
- Multi-page architecture (non-SPA)
- 50+ SEO-friendly tool pages
- Browser-only processing (no backend)
- Shared reusable tool template
- Implemented core image, text, developer, calculator, and security tools
